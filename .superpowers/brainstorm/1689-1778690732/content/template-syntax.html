Template Syntax — Scriban

What gets stored in TemplateVersions.Body and how the engine processes it

Simple Field Binding

Drag a column from the palette → inserts a token. At runtime the engine replaces it with the model value.

Template body:
<p>Dear {{ model.CustomerName }},</p>
<p>Order placed on {{ model.OrderDate }}</p>
<p>Total: {{ model.TotalAmount }}</p>
Model passed at runtime:
new { CustomerName = "John Smith",
      OrderDate = "2026-05-13",
      TotalAmount = "£149.00" }
Loop Block (Repeating Rows)

Drop a "Loop Block" onto canvas → select which collection → drag inner fields. Repeats for each item in the list.

{{ for item in model.OrderItems }}
 <tr>
  <td>{{ item.ProductName }}</td>
  <td>{{ item.Quantity }}</td>
  <td>{{ item.UnitPrice }}</td>
 </tr>
{{ end }}
Model:
OrderItems = new List { ... }
// collection property, any name
Grid Block (Table with Header)

Like a Loop Block but the editor auto-generates the <thead> row. Columns are configured in the Properties panel.

<table>
 <thead><tr>
  <th>Product</th>
  <th>Qty</th><th>Price</th>
 </tr></thead>
 <tbody>
 {{ for item in model.OrderItems }}
  <tr><td>{{item.Product}}</td>…</tr>
 {{ end }}
 </tbody></table>
Conditionals & Filters

Scriban supports if/else and built-in filters. Developers can use these directly; BAs use the Loop/Grid blocks.

// Conditional section
{{ if model.IsPremium }}
 <b>Premium Member</b>
{{ end }}

// Date formatting filter
{{ model.OrderDate | date.to_string "%d/%m/%Y" }}

// String filter
{{ model.CustomerName | string.upcase }}
