NuGet Package — Public API

TemplateBuilder.Core — what consuming developers install and call

1. Register in Program.cs

One line setup. Registers ITemplateEngine as a scoped service via DI.

// Program.cs
builder.Services.AddTemplateBuilder(options =>
{
  options.ConnectionString =
    builder.Configuration
      .GetConnectionString("TemplateDb");

  // optional
  options.EnableCaching = true;
  options.CacheDurationMinutes = 30;
});
2. Inject & Call

Inject ITemplateEngine anywhere — controllers, services, background jobs.

// Any controller or service
public class OrderController(
  ITemplateEngine engine) : Controller
{
  public async Task<IActionResult> Email()
  {
    var html = await engine.
      RenderAsync(
        templateId: 42,
        model: new {
          CustomerName = "John",
          OrderItems = items
        });
    // html = rendered string
  }
}
ITemplateEngine Interface

Minimal public surface. Easy to mock in unit tests.

public interface ITemplateEngine
{
  // Main render method
  Task<string> RenderAsync(
    int templateId,
    object model,
    CancellationToken ct = default);

  // Render by name instead of ID
  Task<string> RenderByNameAsync(
    string templateName,
    object model,
    CancellationToken ct = default);
}
Error Handling

Typed exceptions so callers can handle cases cleanly.

// Typed exceptions
TemplateNotFoundException
 // templateId not found or inactive

TemplateRenderException
 // Scriban syntax error in body

// Caching behaviour
Template body cached after first load.
Cache invalidated when CurrentVersionId
changes (on save in designer).

ViewBag.TemplateHtml = await engine.RenderAsync(id, model);
